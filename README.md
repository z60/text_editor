# 文本编辑器

一个本地运行的代码/文本编辑器。打开即用，粘贴代码自动上色，内置行排序、去重、大小写转换、批量替换、英汉互译、代码格式化，支持把多个文件粘贴成可点击路径、把单个文件拖进来直接打开。

---

## 一、启动

**方式 1（推荐）**：双击 `start-editor.bat`，会自动打开浏览器进入编辑器。

**方式 2**：命令行执行

```bat
npm start
```

然后访问 <http://127.0.0.1:5173/>。

**方式 3（最省事）**：装一次「托盘图标 + 开机自启」，以后在 Windows 右下角通知区域（「向上箭头」展开的隐藏图标区）双击图标就能打开，见下面的「托盘图标 / 开机自启」。

> 第一次运行如果缺少依赖，`start-editor.bat` 会自动执行 `npm install`。
> 之所以要起一个本地服务而不是直接双击 `index.html`，是因为浏览器只在 `http://localhost` 这类安全上下文里开放「文件系统访问 API」，直接 `file://` 打开会失去「直接覆盖保存到原文件」的能力。

### 托盘图标 / 开机自启

在 Windows 右下角通知区域放一个图标，双击即启动服务并打开编辑器；设置开机自启后每次登录自动驻留，随用随点。

| 想做什么 | 怎么做 |
| --- | --- |
| 装上托盘并设置开机自启（会立刻启动托盘） | 双击 `install-autostart.bat` |
| 取消开机自启 | 双击 `uninstall-autostart.bat` |
| 只手动起个托盘，不设置自启 | 双击 `start-tray.vbs`（不闪黑框） |
| 命令行方式 | `powershell -NoProfile -ExecutionPolicy Bypass -File tray.ps1 [-Open] [-Status] [-Install] [-Uninstall]` |
| 只想看服务状态（不动任何进程） | `powershell -NoProfile -ExecutionPolicy Bypass -File tray.ps1 -Status` 或直接跑 `server-check.ps1` |

托盘图标上的菜单：

| 操作 | 效果 |
| --- | --- |
| 双击图标 / 右键「打开文本编辑器」 | 启动服务（已在跑就直接用）并打开浏览器；**发现是在跑旧代码的服务会自动换成当前代码的** |
| 右键「重启编辑器服务」 | 停掉当前服务再起一个新的（改完 `server.js` / `translate.js` 后手动换新用） |
| 右键「停止编辑器服务」 | 停掉当前服务（托盘起的、或上次自启留下的旧服务都能停） |
| 右键「打开项目文件夹」 | 用资源管理器打开项目目录 |
| 右键「开机自动启动」 | 勾选/取消开机自启（等价于两个 `.bat`） |
| 右键「创建桌面快捷方式」 | 在桌面创建 `TextEditor.lnk` |
| 右键「退出」 | 关掉托盘图标（已经在跑的编辑器服务不受影响） |

细节说明：

- **单实例**：重复启动不会出现第二个图标（命名互斥体；上次被强制结束时留下的「已遗弃」互斥体也能正常接管）。
- **端口自适应**：5173 被占用时服务自动换到 5174、5175……，实际端口写在 `.server-port` 里，托盘按它打开，所以永远打得开。
- **不会重复起服务**：托盘打开编辑器时会先看 `.server-port` 记的端口，没响应就回退探测默认的 5173；已经有服务在跑就直接复用（并把端口文件修正回去），不会又起一个、在机器上并排躺两个。
- **会识别「旧代码的服务」并自动换新**（`server-check.ps1`）：页面上的 `index.html`、`js/*.js`、`css` 是每次请求现读磁盘的，但**翻译接口这类后端能力是 node 进程启动时载入的**。如果复用的服务是改动 `server.js` / `translate.js` **之前**启动的，就会出现「前端是新的、翻译接口是旧的」这种半新半旧状态（症状：`Ctrl+Shift+空格` 提示本地服务没有翻译接口，而 `start-editor.bat` 起的新服务却正常）。
  判定办法：`server.js` 提供 `GET /api/version` 自报 `startedAt`，拿它和 `server.js`、`translate.js` 的修改时间比——只要文件的修改时间晚于服务启动时间，就认为这个服务在跑旧代码；确认端口上确实是本项目的页面（`id="toolbar"`）且占用者是 `node` 之后，才把它停掉，再起一个当前代码的服务，并弹出气泡提示。**别的程序占用端口时一律不碰。**
  随时可以自己看一眼：`powershell -NoProfile -ExecutionPolicy Bypass -File server-check.ps1`。
- **`.ps1` 必须存成 UTF-8 with BOM**：本机 ANSI 代码页是 932（日文），`powershell.exe`（5.1）读取**没有 BOM** 的 UTF-8 脚本时会按 CP932 解码，中文变成乱码轻则菜单显示错字、重则把引号/括号撕坏导致**脚本静默不执行**。所以 `tray.ps1` 和 `server-check.ps1` 都带 BOM（改这两个文件时请保留 BOM）。
- **全 ASCII 启动脚本**：COM 建快捷方式时要把路径转成 ANSI，中文会变成 `?` 导致保存失败；`.bat` 里的中文也会被 cmd 按 CP932 解码撕碎。所以 `.bat` 的文件名和内容一律用 ASCII，自启快捷方式叫 `TextEditor.lnk`，放在「启动」文件夹（`shell:startup`）里。
- **失败可见**：托盘起不来时不会悄悄消失，会在项目文件夹写 `tray-error.log` 并弹窗提示（脚本**语法/编码**错误发生在所有代码之前，这种情况连弹窗都没有，用上面的 `-Status` 就能看出服务没起来）。
- **图标自给自足**：`icon.ico` 缺失时会自动生成一个；再失败就退回系统默认图标，不影响功能。

### 文本转换的细节

- **大小写转换**：用 `Alt+Q` / `Alt+E`，或者在工具栏点「大写」/「小写」。`Alt+E` 在 Windows 的 Chrome / Edge 上会被浏览器拿去开菜单（页面拦不住），所以另外挂了 `Shift+Alt+E`；都不顺手的话，在「快捷键设置」里改成自己喜欢的键即可。
- **批量文字替换**（`Alt+R`）：
  - 点「＋ 添加一条规则」可以加多条，**按从上到下的顺序依次应用**（上一条的结果会喂给下一条），所以「foo → bar、bar → baz」的结果是全部变成 baz；
  - 普通模式里 `查找内容` 是**纯字面量**（`.` `*` `(` 这些不需要转义），替换内容里的 `$` 也不会被当成反向引用；想用 `\n`、`\t` 表示换行/制表符可以直接写；
  - 勾上「正则表达式」后按正则处理，替换内容支持 `$1` / `$&` 这类反向引用；正则写错会当场标红提示「第几条规则有问题」，并且**不会**动文档；
  - 有选区时默认只替换选区，也可以切换成整个文档；预览区会显示改动附近的片段；
  - 规则会记住（存在浏览器本地），下次按 `Alt+R` 直接带出上次那套。
- **英汉互译**（`Ctrl+Shift+空格`）：必须有选中文字，否则只提示不动文档。方向按内容自动判断（中文多就翻英文，英文多就翻中文）。长文字会**自动分块**逐段翻译再拼回原来的换行结构，译文写回时会**整段记成一步**，`Ctrl+Z` 一次撤销。
  - 请求不直接由页面发出去（跨域会被挡），而是交给本地服务端 `POST /api/translate`，由服务端按 **腾讯交互翻译 → 有道翻译 → Google 翻译 → MyMemory** 的顺序重试，某一家挂了会自动换下一家，全挂才会在状态栏报错；状态栏会显示这次实际用的是哪家。
  - 因为是机翻，**失败或断网时原文一动不动**，不会把文档搞坏；不想联网就用下面的离线转换。
  - 提示「**本地服务还在跑旧代码（没有翻译接口）**」时：这个服务是在 `server.js` / `translate.js` 改动之前启动的，在托盘图标上右键「重启编辑器服务」（或重新双击托盘图标）就会自动换成新的；托盘会用 `/api/version` 自动识别这种半新半旧的服务并换掉，见上面的「托盘图标 / 开机自启」。
- **中英标点 / 全角半角转换**（离线）：默认键位空着，可以从工具栏「标点」按钮进，或在「快捷键设置」里绑一个键。方向可以手动选（默认按内容猜），并且刻意保留了**必须保留**的情况：`3.14` 的小数点、`1,000` 的千分位、`10:30` 的冒号、`don't` 的撇号都不会被改坏；引号按出现顺序配对成 `“ ”` `‘ ’`。

## 三、自定义快捷键

点工具栏的 **「快捷键」** 按钮（或使用说明窗口里的「快捷键设置」）：

1. 找到想改的功能，点它右边的按键按钮；
2. 按钮变成「请按下新的快捷键…」，这时**直接按你想要的组合键**；
3. 设置立刻生效并自动保存（存在浏览器本地，下次打开还在）。

规则与细节：

- **Esc** 取消本次设置；**Backspace / Delete** 清空该功能的快捷键（变成「未设置」）。
- 必须带 `Ctrl` 或 `Alt`（功能键 `F1`~`F12`、`Tab`、`Esc`、`Home`/`End`/方向键等除外），否则会提示「需要配合 Ctrl / Alt 使用」——避免单个字母抢占打字。
- 如果按键**已被别的功能占用**，会提示「已被「xxx」占用」，不会覆盖。
- 点某一行的「恢复默认」只重置这一项；窗口底部「全部恢复默认」一次清空所有改动。
- 修改过的项会以蓝色高亮显示，方便看出哪些是自定义的。
- 快捷键在**焦点不在编辑区时同样生效**（比如刚点完工具栏按钮），但如果你正在对话框的输入框里打字，只放行带 `Ctrl+Alt` / `Alt` 或功能键的组合，不会抢走正常的输入。
- **复制 / 剪切 / 粘贴（Ctrl+C / X / V）由浏览器接管，无法改键**，所以在设置列表里不提供；这是网页应用的限制。
- 清空某个快捷键后，编辑器内置的同名默认键仍可能生效（例如 Ctrl+Z 撤销、Ctrl+A 全选），这一点在设置窗口底部也有说明。

可自定义的功能一共 34 项，默认键位如下（「使用说明」窗口里的列表是按当前实际键位**实时生成**的，改完键位那里也会同步变）：

| 分组 | 功能 | 默认键 |
| --- | --- | --- |
| 文件 | 新建文件 / 打开文件 / 保存 / 另存为 / 关闭标签 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` / `Ctrl+W` |
| 编辑 | 撤销 / 重做 / 全选 / 插入缩进 / 减少缩进 | `Ctrl+Z` / `Ctrl+Y` / `Ctrl+A` / `Tab` / `Shift+Tab` |
| 编辑 | 注释、取消注释 / 单词自动补全 | `Ctrl+/` / `Ctrl+Space` |
| 文本处理 | 按行升序 / 按行降序 / 删除重复行 | `Ctrl+Alt+A` / `Ctrl+Alt+D` / `Alt+M` |
| 文本处理 | 格式化代码 / 重新识别语言 | `Ctrl+Alt+F` / （未设置） |
| 文本转换 | 小写转大写 / 大写转小写 / 批量文字替换 | `Alt+Q` / `Alt+E`（`Shift+Alt+E` 也行）/ `Alt+R` |
| 文本转换 | 英汉互译（联网）/ 中英标点·全角半角（离线） | `Ctrl+Shift+Space` / （未设置） |
| 视图 | 自动换行开关 / 切换主题 | `Alt+Z` / （未设置） |
| 比较合并 | 开始比较 / 下一处差异 / 上一处差异 | `Ctrl+Alt+M` / `F7` / `Shift+F7` |
| 比较合并 | 用左侧覆盖右侧 / 用右侧覆盖左侧 / 退出比较 | `Ctrl+Alt+→` / `Ctrl+Alt+←` / （未设置） |
| 比较合并 | 标记行对齐起点 / 清除全部行对齐 | `F2`（`F12` 也行）/ （未设置） |
| 帮助 | 使用说明 / 快捷键设置 | `F1` / （未设置） |

需要新增可配置的功能时，只要在 `js/app.js` 顶部的 `COMMANDS` 注册表里加一条，快捷键设置界面和「使用说明」会自动出现这一项，无需改别的地方。

### 关于「可点击的路径」的说明

浏览器出于安全限制，**拿不到粘贴文件的完整磁盘路径**（这是所有网页应用的共同限制，只有 Electron 之类的桌面壳才能拿到）。所以：

- 如果剪贴板里同时带有路径文本（部分文件管理器会带），编辑器会优先显示真实路径；
- 否则显示文件名，鼠标悬停提示「点击打开：xxx」，点击后把该文件内容读出来开成新标签。

**什么情况会生成路径、什么情况直接打开**：

| 你做了什么 | 结果 |
| --- | --- |
| `Ctrl+V` 粘贴 1 个或多个文件 | 一律插入可点击路径（粘贴常常是「把文件名记下来」，所以不抢着开标签） |
| 拖入 **1 个**文件 | **直接打开成新标签页** —— 拖拽这个动作本身就是「我要打开它」 |
| 拖入 **2 个以上**文件 | 插入可点击路径，一行一个 |
| 拖入的是**文件夹** | 不当成文件打开，退回插入可点击路径（浏览器会把文件夹也塞进 `dataTransfer.files`，但它是读不出内容的） |

拖入单个文件打开时，走的是和 `Ctrl+O` 完全一样的那条路：自动判定二进制、自动识别编码（UTF-8 / UTF-16 / Shift_JIS / EUC-JP…）、自动识别语言并高亮；因为是拖进来的 `File` 对象，没有文件句柄，所以 `Ctrl+S` 保存时会弹出「另存为」。

如果你需要「显示真实绝对路径 + 点击用系统默认程序打开」，那需要换 Electron 壳，可以后续扩展。

## 四、两文件比较 / 合并

点工具栏的 **「比较」**（或按 `Ctrl+Alt+M`），弹出选择窗口：

```
┌ 文件比较 / 合并 ────────────────────────────────────────┐
│ [选择文件…] [⇄ 交换左右]  一次选两个会自动一左一右…       │
│ ┌ 待分配（拖到左边或右边，或者点一下放进去）───────────┐ │
│ │ (chip) (chip) (chip)                                 │ │
│ └──────────────────────────────────────────────────────┘ │
│ ┌ 左 ─ 把文件拖到这里 ┐   ┌ 右 ─ 把文件拖到这里 ┐        │
│ │ (chip ✕)            │   │ (chip ✕)            │        │
│ └─────────────────────┘   └─────────────────────┘        │
│ □忽略行尾空白  □忽略大小写                               │
│                                 [取消] [开始比较]        │
└──────────────────────────────────────────────────────────┘
```

**怎么分配左右**（三种方式随便挑）：

| 操作 | 结果 |
| --- | --- |
| 一次**选 / 拖入两个文件** | 自动一个分到左边、一个分到右边 |
| **只选 / 拖入一个文件** | 停在「待分配」区，自己拖到左边或右边；也可以点一下它，自动放进空的那一侧 |
| 直接把文件**拖到左边框或右边框** | 拖到哪一侧就归哪一侧（一次拖两个：第一个归这一侧，第二个归另一侧） |

补充说明：

- 「选择文件…」用的是系统文件选择框（可多选）；也可以直接把文件从资源管理器拖进窗口；
- 已经打开的标签会**列在待分配区**，可以直接拖进左右两侧，不用重新找文件；
- 想换：点 chip 上的 ✕ 移出回到待分配，或用「⇄ 交换左右」；
- 只放一侧也能比较（另一侧当空文件处理），按钮会变成「开始比较（另一侧为空）」。

点「开始比较」后屏幕变成左右两块：

**1. 两个文件用不同颜色区分**

| | 左侧 | 右侧 |
| --- | --- | --- |
| 标题栏 | 蓝色底 + 「左」标 | 琥珀色底 + 「右」标 |
| 编辑区底色 | 冷白偏蓝 | 暖白偏黄 |
| 行号栏 | 淡蓝 | 淡黄 |
| 差异行底色 | 红（这块内容在左边是旧/被删的） | 绿（这块内容在右边是新/被加的） |
| 行内逐词标色 | 深红（具体改了哪几个字） | 深绿 |

**2. 内容不一致的地方会变色**

- 整行级别：改动/删除的行在左边是红底，新增/改动的行在右边是绿底；
- 词级别：同一行里只有几个字不同时，会把这几个字单独标成更深的红/绿，一眼看出改了什么；
- 当前所在的那一处差异会额外加深底色；
- 行数不一样的地方（一边多几行、一边少几行）会用**斜纹占位块**补上，保证左右行号始终对齐。

**3. 比较视图里的操作**

| 按钮 / 快捷键 | 作用 |
| --- | --- |
| `F7` / `Shift+F7` | 跳到下一处 / 上一处差异，中间显示「第 3 / 12 处」 |
| `Ctrl+Alt+→` | 用左侧内容覆盖右侧当前这处差异 |
| `Ctrl+Alt+←` | 用右侧内容覆盖左侧当前这处差异 |
| `F2` → 点另一边 | **手动行对齐**：见下面的「用 F2 手动对齐两行」 |
| 对齐起点 / 清除对齐 | 上面这条的按钮版；清除后占位块恢复按差异自动计算 |
| 重新比较 | 手动重算（编辑后 0.4 秒也会自动重算） |
| 忽略行尾空白 / 忽略大小写 | 比较时忽略这类差异 |
| 保存左侧 / 保存右侧 | 把这一侧的内容写回它对应的文档并保存（覆盖原文件） |
| 退出比较 | 回到普通编辑视图（有未保存的改动会先确认） |

**用 F2 手动对齐两行**

占位块是**按差异自动**算出来的，可有时候你想对齐的是「你自己认为对应的两行」（比如两边前面差了几行、或者内容被搬过位置）。这时候可以手动指定：

1. 在左（或右）边把光标放到某一行，按 **`F2`**（`F12` 也认）—— 这一行会被标成橙色虚线（**待对齐**），状态栏提示「待对齐：右 5 行，点另一边」；
2. 用鼠标点另一边的**对应行** —— 这两行立刻被排到**同一行**上（谁在上面，就在谁上面垫占位块），并标成蓝色实线；
3. **可以继续配下一对**：再按 `F2`、再点另一边即可，**之前配好的对齐会保留**，多对叠加互不取消；
4. 之后两边照旧 1:1 同步滚动：因为对齐是靠占位块做出来的，往下滚这些配对行始终在同一行；
5. 不想对齐了点 **「清除对齐」** 一次清掉全部配对，占位块恢复按差异自动计算。

举个例子（左边 aaa/bbb/ccc，右边 111/aaa/aaa/ccc/bbb）：

```
默认                              配两对之后（右2↔左1、右3↔左2）
左        右                      左        右
[占位]    111                     [占位]    111
aaa       aaa                     aaa       aaa   ← 第 1 对
bbb       aaa                     bbb       aaa   ← 第 2 对
ccc       ccc                     ccc       ccc   ← 相同行跟着对上
[占位]    bbb                     [占位]    bbb
```

再比如左边 111/222/start、右边 3333/111/111/start：在右边第 3 行按 `F2`、再点左边第 1 行之后

```
左        右
[占位]    3333
[占位]    111
111       111   ← 左边 111 对齐到右边第 3 行
222       [占位]
start     start ← 结尾的 start 仍然对得上
```

细节：

- **只影响占位块的排法，不改差异结果**：差异行底色、逐词标色、`F7` 的差异列表、左右覆盖全都照旧；配对行之间 / 最后一对以下仍各自按差异补占位，所以其它相同行不会因此错位；
- 同一行只能配一对：新配的对如果和旧的**共用**左边或右边同一行，旧的会被替换（状态栏会说明）；其余配对不受影响；
- 按 `F2` 的时候行还没完成对齐，再点**同一侧**只是把标记挪过去；点**另一侧**才算完成；
- 小文件（几行、没有滚动条）一样有效 —— 因为靠的是占位块，不是滚动位置；
- 退出比较视图会自动清除全部对齐。

其它细节：

- 两个窗格**可以正常编辑**，`Ctrl+Z` 能撤销，包括撤销「覆盖」这类合并动作；
- 两边**滚动同步**，滚一边另一边跟着走，配合占位行对齐，始终看的是同一段；手动行对齐（`F2` + 点另一边）之后，占位块按你指定的那两行重排；
- 比较时排序（`Ctrl+Alt+A/D`）、去重（`Alt+M`）、格式化（`Ctrl+Alt+F`）都能照常用，作用在**当前焦点所在的那一侧**；
- 差分算法是自己实现的 Myers 差分（先掐掉公共前后缀），2000 行、几十处差异的文件实测毫秒级完成；差异大到超出计算上限时会退化成「整块标记」并提示；
- 只有比较视图里点过「保存左侧 / 保存右侧」，改动才会写回文档；直接退出会丢弃（退出前会提示）。

## 五、格式化能力对照

| 语言 | 使用什么 | 效果 |
| --- | --- | --- |
| JavaScript / JSX / TypeScript / TSX / HTML / Vue / CSS / SCSS / LESS / Markdown / YAML | **Prettier** | 精确格式化，缩进、换行、空格、引号全部重排 |
| JSON / JSONC | **Prettier** | 对象、数组按层级换行缩进（压缩成一行的 JSON 也会被展开）；数字、转义字符等字面量**原样保留**（`1.0`、`1e5`、大整数、`\uXXXX` 不会被改写），带注释和尾逗号的 JSONC 同样支持 |
| SQL | **sql-formatter** | 子句换行对齐，关键字大写（自动尝试 mysql / postgresql / sqlite 等方言） |
| XML | **js-beautify** | 标签层级美化 |
| Java / C / C++ / C# / Kotlin / Scala / Go / Rust / Swift / Dart / PHP / Pascal / Verilog 等 | **内置结构重排** | **语句断行**：挤成一行的代码会摊开 —— `;` 之后、`{` 之后、`}` 之前、`case`/`default` 标签之后换行（`for (a; b; c)` 括号里的分号不算），`} else {` / `} catch {` 留在同一行，`int[] a = {1, 2, 3}` 这种初始化不会被摊开；**缩进**：按 `{ }` 块层级重排，`foo(a,` + 续行会多缩一层；**空格**：运算符两侧补空格（`=`、`==`、`+`、`&&`、三元 `? :`、复合赋值…），`if`/`for`/`while` 后补空格（`if (x > 0)`），逗号后补空格、`;` 后补空格；`std::`、`p->x`（C/C++/PHP）、`++`、`a?.b`、`??`、`??=`、`...` 不会被拆坏；泛型 `List<String>`、`Map<K, List<V>>`、`new ArrayList<>()` 整段保持（只补里面的逗号空格），`a < b` 这种比较不会误当泛型；**字符串和注释里的内容一个字都不动** |
| Python | **内置 Python 格式化** | **结构整理**：顶层 `;` 分行；单行写法的复合语句摊开（`def f(a,b): return a+b` → 两行）；**超过宽度上限的一行按最外层括号摊成一项一行并补尾逗号**（Black 风格，例如十几项挤在一起的嵌套 dict，短的就保持一行）；**缩进**按原有相对层级统一宽度（缩进即语法，绝不重排代码块归属）；**行内空格**按 PEP8：赋值号两侧留空格（`x = 1`）、关键字参数与默认值不留空格（`f(a=1)`）、逗号后留空格、字典/注解冒号后留空格、切片不留空格（`a[1:2]`）、括号内不留空格、行内注释前两个空格；`**` 幂、`//` 整除、`*args`/`**kwargs` 解包、一元负号都正确区分；**三引号字符串（含内部缩进）和注释原样保留** |
| Ruby / YAML / INI / TOML 等 | **内置缩进规范化** | 保持行内容不变，按原有相对层级把每层缩进统一成设定宽度（不会猜错代码块归属，安全可预期） |

格式化结果可以用 `Ctrl+Z` 一步撤销。

> 说明：Java / C 系和 Python 用的是**内置**格式化（浏览器里没有可用的 Java/Python 格式化器，Prettier 只有 JS 系的插件）。
>
> - **Java / C 系**做的是「语句断行 + 缩进 + 空格」：粘贴过来挤成一行的代码会按 `;`、`{`、`}`、`case` 摊成一句一行，再统一缩进、补齐运算符周围的空格。已经分好行的代码只补空格、不动行结构（空行保留）。
> - **Python**做的是「结构整理 + 缩进 + 行内空格」：`;` 分行、单行复合语句摊开、超过宽度上限的表达式按最外层括号摊开（Black 风格，短的不动）。因为缩进就是语法，**绝不重排代码块归属**。
> - 两者都**只在括号 / 分号 / 大括号这些安全位置断行**（不会按字数硬折），**不合并语句**；因为只增删空白与尾逗号、字符串与注释整段跳过，所以不会改变程序语义，并且保证**幂等**（格式化两次 = 一次）。
>
> 如果打开对话框时文档语言还是「纯文本」（比如刚打字、或打开的文件没走到自动识别），对话框会就地再识别一次并预选对应语言，不会闷头按「纯文本」只重排缩进。
